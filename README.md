# 🌤️ Weather App

A clean and responsive web-based Weather App that shows real-time weather data and 24-hour forecasts using the OpenWeatherMap API. Just enter your city, hit search, and get instant weather details and forecasts.

---

## 🚀 Features

- 🔎 Search by city name
- 🌡️ View current temperature and weather conditions
- 🕒 See hourly forecast in 3-hour intervals for the next 24 hours
- 🖼️ Display weather icons dynamically
- 🎨 Responsive and modern design

---

## 🛠️ Tech Stack

- HTML5 – for structure
- CSS3 – for design & layout
- JavaScript (ES6) – for functionality & API handling
- OpenWeatherMap API – for weather data

---

## 📁 File Structure

weather-app/
├── index.html       # Main HTML structure
├── style.css        # CSS styling for layout and design
└── script.js        # JavaScript to handle API calls and DOM updates

---

````
## 🔧 Setup Instructions


1. Clone the repository:

```bash
git clone https://github.com/yourusername/weather-app.git
````

2. Replace the `apiKey` in `script.js` with your OpenWeatherMap API key:

```js
const apiKey = 'YOUR_API_KEY';
```

3. Open `index.html` in your browser to use the app.
